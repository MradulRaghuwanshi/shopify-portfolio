# SparkServes Shopify Portfolio Website

## Files
- index.html - website structure/content
- style.css - responsive styling and animations
- script.js - interactions, reveal animations, mobile menu, and quote-request mailto handler

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the three files to Netlify, Vercel, GitHub Pages, or any standard web host.

## Notes
The quote form is frontend-only and opens the visitor's default email client addressed to contact@sparkserves.com. For production lead capture, connect the form to a backend or form service.
